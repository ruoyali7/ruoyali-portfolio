# Ruoya Li — Creative Technology Portfolio

Portfolio website for Ruoya Li, positioned as a **Software Engineer & Creative Technologist** working across software, AI, 3D, and creative workflows.

## Product direction

The site should help a recruiter understand the positioning within 10–20 seconds, then quickly find evidence for either software-engineering or 3D/AI/creative-technology roles. It should feel like a calm, technically credible creative-technology lab: not a traditional architecture portfolio, generic developer portfolio, or AI-art gallery.

## Current status

This repository is currently in the planning and content-audit stage. See [docs/roadmap.md](docs/roadmap.md) for the implementation phases and acceptance criteria.

## Primary routes

- `/` — positioning, selected work, capabilities, experience
- `/work` — curated project index
- `/work/:slug` — case studies
- `/experiments` — smaller explorations
- `/about` — background and current focus
- `/resume` — resume and external links
